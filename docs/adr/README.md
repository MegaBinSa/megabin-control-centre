# Architecture Decision Records

Architecture Decision Records capture durable decisions for MegaBin Control Centre. Accepted ADRs are authoritative within their scope and are subordinate to the system blueprint unless an ADR explicitly records an approved blueprint change.

## Status values

- **Proposed:** under review and not yet binding.
- **Accepted:** approved and binding.
- **Superseded:** replaced by a later ADR, which must be linked.
- **Deprecated:** retained for history but no longer recommended.

Do not edit an accepted decision to hide a later change. Add a new ADR and mark the earlier record superseded.
