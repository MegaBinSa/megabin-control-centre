# Office Communications Workflow

Authorized Office users can review provider health, intent and fallback history, delivery outcomes, inbound match/command status, and request an approved `test_message`. Test sends remain asynchronous and pass through environment recipient safety. The workspace is not a CRM inbox and does not allow unrestricted production free text.

Client communication history uses the same scoped read model and exposes operational history without provider payloads. Inbound `SKIP` is visible as recognized only; Phase 4E offers no approval or route action.
